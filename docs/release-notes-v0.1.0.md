# Enoki v0.1.0 — Release Notes

> 公開済み: https://github.com/hsm-hx/enoki/releases/tag/v0.1.0

---

## Enoki v0.1.0 — 初回公開

**Enoki は、macOS のデスクトップにキャラクターが常駐するマスコットアプリです。**
時間帯や状況に合わせて声をかけてくれます。ネットワーク通信は一切せず、
アクセシビリティ・画面収録・入力監視の権限も要求しません。見ているのは時刻と自分の状態だけです。

公式デモキャラクター **御影栞** を同梱しているので、clone してすぐ動かせます。
台詞（`dialogue.json`）とスプライトシートを差し替えれば、**自分のキャラクターを住まわせられます**。

## この Release で使えること

- **デスクトップ常駐** — ドラッグで好きな位置へ。全スペース表示 / 常に最前面 / クリック透過 /
  表示倍率（50〜150%）の切り替え
- **待機・居眠り・リアクション** — 待機アニメーションをランダムに切り替え、無操作が続くと居眠り、
  クリックで手を振る・跳ねる
- **時間帯と状況に応じた声かけ** — 仕事・水分・休憩・昼食・励まし・雰囲気・掛け合いの各カテゴリを、
  時刻と周期で選んで吹き出しに表示
- **`dialogue.json` による台詞管理** — 話者を JSON で宣言でき、**1 人でも複数人でも**書けます。
  吹き出しの表示名と立ち位置も JSON で決まります（1 人なら中央、2 人なら左右に自動配置）
- **Quiet Mode / 仕事中モード** — 「1 時間静かに」「今日の仕事終了まで」「会話 OFF」、
  仕事中かどうかで話す内容を変える切り替え
- **見た目プロファイル (Appearance Profiles)** — スプライトセットと台詞カテゴリの組み合わせを
  `profiles.json` で定義し、土日・祝日・イベント日などの条件で自動的に切り替え
- **スプライト形式** — `pet.json` + 8 列 × 9 行のシート、`manifest.json` + ストリップ画像に対応。
  **Codex Pet のアセット形式と非公式に互換**です（Enoki は OpenAI とは無関係で、
  承認・提携・推奨を受けたものではありません）
- **スプライト生成スクリプト** — ポーズ画像 1 枚ずつからアトラスを作る `scripts/build_atlas.py`。
  全コマで身長と立ち位置を自動で揃えます

## 動作確認環境

| 項目 | 内容 |
|---|---|
| 対応 OS | macOS 13 (Ventura) 以降 |
| 動作確認済み | macOS 26 / Apple Silicon / Swift 6.2.4 |
| ビルド | Swift 5.9 以降のツールチェイン（Xcode 15 以降または Command Line Tools） |
| 外部依存 | なし（オフラインでビルドできます） |

## セットアップ

```bash
git clone https://github.com/hsm-hx/enoki.git
cd enoki
make run
```

依存パッケージのインストール手順はありません。詳しくは
[README](../README.md#installation--development) を参照してください。

配布用の `.app` は `make app`、テストは `make test` です。

## 自分のキャラクターに差し替える

[docs/customization.md](customization.md) に、台詞・スプライト・見た目プロファイルの
差し替え方をまとめています。[examples/](../examples/) には、コピーして書き換えるだけの
サンプル（1 人用 / 2 人用）があります。

```bash
cp -R examples/solo ~/.codex/pets/my-character
cp Sources/Enoki/Resources/DefaultSkin/spritesheet.png ~/.codex/pets/my-character/
ENOKI_SKIN_DIR=~/.codex/pets/my-character swift run Enoki
```

## 既知の制限

- 動作確認は **macOS 26 / Apple Silicon のみ**です（Intel Mac・他バージョンは未検証、
  Windows / Linux は非対応）
- **1 プロセスにつきキャラクターは 1 体**です。2 人組に見せる場合は 1 枚の絵に 2 人を描きます
- **キャラクターの差し替えは JSON とファイル配置**で行います。GUI のエディタやアプリ内での
  キャラクター変更機能はありません
- **設定ウィンドウはありません**（操作はすべてメニューバー）。細かい調整は JSON の編集が必要です
- **スキン・台詞のホットリロードはありません**（メニューの「スキン > 再読み込み」を使ってください）
- **台詞は JSON からの選択だけ**で生成はしません。同梱デモは 30 会話です
- **声かけは完全に時間ベース**です（入力内容・画面・他アプリを読まないため、実際の作業状況は見ていません）
- 素材は 1x のため Retina では拡大表示になります
- UI は日本語固定です
- 配布バイナリは提供していません。**ソースからビルドしてください**（署名はアドホック署名です）
